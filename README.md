# إنجازي — Injazi

تطبيق Flutter لأندرويد لمتابعة الإنجازات اليومية: تسجّل ما أنجزته كل يوم، وتحدّد
إنجازاتك وأهدافك بنفسك، مع خطط متكرّرة وتقويم بالساعات وتذكيرات ذكية.

## المزايا

- **إنجازات اليوم**: إضافة سريعة، خطوات فرعية، وسوم، أولويات، فئات قابلة للتخصيص.
- **خطط متكرّرة**: يوميًا / أسبوعيًا (اختيار أيام مثل «كل ثلاثاء») / كل ن يوم /
  شهريًا، مع تاريخ بداية ونهاية اختياري، وإيقاف مؤقت وتخطّي أيام.
  - تُحسب **أيام الدوام** وأيام الراحة في كل خطة حسب أيام الدوام المحددة في الإعدادات.
- **تقويم غني**: عرض شهري وأسبوعي ويومي + خط زمني بالساعات («١٩:٠٠ → ٢٠:٠٠»).
- **تذكير نهاية اليوم (٢١:٠٠ افتراضيًا)**: إشعار يسرد ما لم يُنجز بعد، وقابل
  للتعديل من الإعدادات. مع أزرار «أنجزت ✓» و«تأجيل» تعمل من الإشعار نفسه.
  إضافة إلى تذكير الصباح، والتنبيهات المتكرّرة، والصوت المخصّص والاهتزاز.
- **أحداث يومية (سجل دائم)**: تسجّل ما حدث في يومك (عنوان، وقت، مكان، دقائق،
  ملاحظة، فئة، نجمة) مع تبويبات: الكل / المميّزة / القادمة / السابقة، وفلترة
  بيوم محدّد، وبحث. **الأحداث لا تُحذف تلقائيًا أبدًا** — تبقى في السجل للأبد.
- **قفل التطبيق بكلمة سر**: لا يفتح التطبيق إلا بعد كتابة كلمة السر، وتُخزَّن
  كبصمة PBKDF2‑SHA256 (٨٠٠٠٠ تكرار) ولا تُحفظ كلمة السر نفسها. مع مهلة سماح
  بعد الخروج من التطبيق (٠–٥ دقائق)، وقفل فوري بضغطة، ومنع لقطات الشاشة اختياريًا،
  وخيار مسح كل البيانات عند نسيان كلمة السر.
- **نسخة احتياطية مشفّرة**: تصدير ملف `.injaz` مشفّر بكلمة سر (AES‑256‑CTR +
  HMAC‑SHA256 مع PBKDF2)، ويُحفظ عبر مُنتقي الملفات الرسمي في أندرويد، مع بديل
  النسخ إلى الحافظة، واستيراد باختيار ملف أو بلصق النص، وتقارير واضحة للأخطاء
  (كلمة سر خاطئة / ملف تالف / مُعدَّل / ليس نسخة).
- **تقارير وإحصاءات**: نسبة الإنجاز، السلسلة، سجل الأيام، توزيع الفئات،
  أكثر ساعات الإنتاج، وخريطة حرارية للأشهر.
- **شارات ومستويات**: نقاط خبرة ومستويات و١٢ شارة تحفيزية.
- **مؤقّت تركيز**: جلسات تركيز مرتبطة بالخطة/المهمة مع احتساب دقائق التركيز.
- **بحث وملاحظات يومية وخلفية مزاجية**، ونسخ احتياطي عادي (JSON) أو مشفّر بكلمة سر.
- **تصميم أنيق**: عربي RTL أصلي، ٨ ثيمات لونية، وضع فاتح/غامق، كثافة عرض،
  حجم خط، وحواف قابلة للضبط، وخطوط Cairo و Readex Pro.
- **أيقونة هادئة** وصوت إشعار مخصّص (٤ أصوات: هادئة، نقية، جرس، خفيفة).

## البناء

```bash
flutter pub get
flutter analyze
flutter test
flutter build apk --release      # ينتج build/app/outputs/flutter-apk/app-release.apk
```

> نسخة الإصدار تُوقّع بمفتاح تجريبي ثابت مرفوع مع المشروع
> (`android/app/injazi-test-signing.p12`) كي تُثبَّت النسخة الجديدة فوق القديمة
> دون حذف التطبيق. **لا تستخدم هذا المفتاح للنشر على المتجر**؛ أنشئ keystore
> خاصًا بك وضَع إعداداته في `android/app/build.gradle.kts` ولا ترفعه للمستودع.

## تنزيل ملف APK الجاهز

كل نسخة تُدفع إلى هذا الفرع تُشغّل تلقائيًا: `flutter analyze` ثم `flutter test`.
ويمكن تنزيل ملف APK جاهز للتجربة دون أي إعداد محلي:

1. افتح صفحة **Actions**: `https://github.com/ogooom11-lgtm/gunluk-20-146-166/actions`
2. اختر آخر تشغيل ناجح باسم «بناء APK».
3. من قسم **Artifacts** نزّل `injazi-release-apk` ثم فك الضغط → `app-release.apk`.

لبناء الملف في تشغيل جديد، أضف `[apk]` في رسالة الـ commit (أو شغّل الـ workflow
يدويًا مع تفعيل `build_apk`). في حال فشل التحليل أو الاختبارات أو البناء، ينشر
الـ workflow تقريرًا مختصرًا كتعليق على الـ commit نفسه يوضّح الأخطاء.

## إن لم تصل الإشعارات؟ (خطوات التحقق)

1. **الإذن**: من التطبيق ← الإعدادات ← الإشعارات، يجب أن تكون «أذونات الإشعارات»
   **ممنوح**، واضغط عليها لمنح الإذن إن كانت مرفوضة. (الإصدارات الحديثة من
   أندرويد لا تسمح بأي إشعار قبل منح هذا الإذن).
2. **الجدولة**: في الشاشة نفسها يوجد «**التذكيرات المجدولة**» يعرض عدد التذكيرات
   المسجّلة فعليًا في النظام ووقت أقرب تذكير، والضغط عليه يعيد الجدولة فورًا.
   إذا كان العدد صفرًا: أضف مهمة لها وقت، أو فعّل «تذكير نهاية اليوم».
3. **المنبّهات الدقيقة**: إن كان «إذن المنبّهات الدقيقة» غير ممنوح، يعمل التطبيق
   تلقائيًا بالجدولة التقريبية (قد يتأخر الإشعار دقائق).
4. **توفير الطاقة**: بعض الهواتف (شاومي/هواوي/سامسونج) توقف التطبيقات في
   الخلفية — اسمح للتطبيق بالعمل في الخلفية من إعدادات النظام.
5. **تجربة فورية**: «معاينة إشعار» ترسل إشعارًا الآن؛ إن ظهرت رسالة فشل فالمشكلة
   في الإذن أو في قناة الإشعارات.

## بنية المشروع

```
lib/
  core/        enums، أدوات التواريخ والأوقات (ميلادي/هجري)، النصوص (ar/en)، النماذج
  data/        التخزين المحلي (SharedPreferences)، حالة التطبيق، مُخطِّط التذكيرات
  services/    الإشعارات (قنوات، أصوات، جدولة، أزرار) + المنطقة الزمنية +
               التشفير وخدمة الملفات (قناة أصلية أندرويد للحفظ/الاختيار الآمن)
  theme/       الثيمات واللوحات اللونية والمقاسات
  ui/          الشاشات والأدوات: الرئيسية، التقويم، الخطط، التقارير، الإعدادات…
test/          اختبارات المنطق الخالص (تواريخ، مهام، خطط، إحصاءات، تذكيرات، نصوص،
               واجهات وتقويم/خط زمني/ورق الإضافة السريعة، وسريان السمة واللغة فورًا)
```

## الخصوصية

كل البيانات تُخزَّن محليًا على الجهاز فقط (بدون حساب أو إنترنت)، ويمكن تصديرها
واستيرادها في أي وقت من: الإعدادات ← البيانات ← نسخ احتياطي.

- التشفير مبني على مكتبة `crypto` الرسمية (PBKDF2‑SHA256 + AES‑256‑CTR + HMAC‑SHA256)
  وتم التحقق من صحته باختبارات متجهات FIPS/NIST داخل `test/secure_data_test.dart`.
- لا تُرسل أي بيانات إلى أي خدمة خارجية؛ الملف المشفّر يخرج من الجهاز فقط عندما
  تختار أنت حفظه/مشاركته.
